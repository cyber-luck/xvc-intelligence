## 4. Verification ladder for the authorized copy (when one exists)

Size/version/isolated-hash coincidences are **not enough**. Required chain, all already implemented and tested:

1. Valid x64/PE32+ PE with a size **exactly 120,181,760 B** (SegmentMetadata) — `reconstruct`;
2. a hash (**Authenticode or raw**) present in the readable `Catalog000.bin` — `catalog`;
3. RSDS GUID/age consistent with the corresponding PDB, when one exists — `cross_validate_rsds_pdb`;
4. documented custody (`--provenance`, recorded as a claim) — `source_provenance.json`.

Without item 2 (or equivalent better evidence), a complete file → `COMPLETE_UNVERIFIED`, never `COMPLETE_VERIFIED`.
